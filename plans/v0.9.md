# v0.9 plan: Game Review AI

## Context
v0.8 is signed off and merged (`main` is clean). ROADMAP v0.9 adds two things on top of the v0.7 LLM stack and the v0.8 Review screen:
- **Explain this move** and **Explain my game** (FR-11.17–11.21), with *Review + Explain my game* and the **AI-reviewed** status that v0.8 left out.
- **A model per AI feature** (FR-1.15): puzzle Explain and Game Review each get their own provider, model and reasoning level. They share the keys, the price table, the per-run cap and the monthly budget.

Branch: `v0.9` from `main`. **No new dependencies. No migration:** `games.analysis_status` already allows `ai_reviewed` (0007 comment), `llm_cache` is keyed by hash, and the feature settings go in `settings`.

## Decisions recorded (Adam, 2026-11-04, v0.9 planning)
| Question | Answer |
|---|---|
| What Game Review uses before you pick a model | **Explain's provider and model** ("Same as Explain"). A model dropdown **on the Review page** lets you pick another. It writes the same Game Review setting as Settings → AI. |
| What's per feature | **Reasoning is per feature.** The per-run cap and the monthly budget are shared. |
| Startup page short form | **Both pickers:** one for Explain's model and one for Game Review's ("Same as Explain" by default). |
| Recommended preset (FR-11.18) | **Build it now, minimal:** up to 3 theme keys plus an optional rating range, validated against the theme registry and `FilterSpec.validate`. Invalid fields are dropped. **Train these** applies it to the Mixer only when you click it, after a confirm. It never touches a saved preset. v0.10 reuses the validator. |

My defaults (veto at approval if wrong):
- **Explain this move works on your moves only.** When your color is *both*/unknown, that means every move. The "you" framing and the refutation don't fit an opponent's move.
- **The cache key also includes the analysis settings** (think time + engine), besides FR-11.20's (game, ply / N, provider, model). Without this, a deeper re-analysis would bring back an explanation grounded on the old evals.
- **`max_tokens`:** Explain this move 1,500 (same as Explain), Explain my game 4,000. I'll update FR-8.14. Reasoning ×2/×4 applies as usual. Worst case for Explain my game on Opus at High is about $0.36, under the $0.50 cap.
- **A re-analysis resets the status** from `ai_reviewed` to `analyzed`. That already happens, because the analysis writer sets `analyzed`.
